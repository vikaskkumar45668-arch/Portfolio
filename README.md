# Vikas K — Software & Web Developer

A responsive portfolio website for Vikas K, a computer science student and aspiring software and web developer.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Deploy to GitHub Pages

The GitHub Actions workflow builds and deploys the site when changes are pushed to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The published site will be available at `https://vikaskkumar45668-arch.github.io/Portfolio/` after the first successful deployment.

## Portfolio sections

- About and technical skills
- CARVIO career guidance project
- Farmer Friendly Consultancy (FFC)
- Education, certifications, and activities
- Contact details

Built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide React.
